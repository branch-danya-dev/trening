# Черновик инструкции участнику

**Не использовать для внешнего набора до review.** Организатор `[ ]`, контакт `[ ]`, версия приложения `[ ]`, период участия `[ ]`, срок хранения переданных данных `[ ]`.

1. Прочитайте согласие и выберите разрешённые виды участия. Фото и диагностический экспорт необязательны.
2. Откройте указанную организатором версию на своём устройстве. Профиль и записи сохраняются в этом браузере. Для важных записей скачивайте backup и храните его в выбранном вами безопасном месте.
3. Заполните профиль, проверьте и зафиксируйте аватар. Отмечайте фактически выполненные действия и съеденную пищу. Не подтверждайте пустой день как отдых или отсутствие еды, если достоверных данных нет.
4. При новом замере вводите только известные величины. Пустое поле означает неизвестное значение. Фото остаются локально; используйте исходные фото, не генерации и не GeometryWarp-изображения. При отказе проверки можно сохранить допустимые ручные факты и оставить прежнюю форму аватара.
5. Гипотеза — оценка, а не обещание результата и не медицинская рекомендация. Сравнение с последующим фактом не заменяет проверку реальной точности на независимых данных.
6. При сообщении о конфликте вкладок сохраните незаписанный ввод удобным способом, перезагрузите и повторно проверьте данные. При сообщении о нехватке места экспортируйте backup; удаление производных изображений не должно заменяться удалением recovery marker.
7. При предложении обновить приложение закончите/сохраните работу, закройте все его вкладки и откройте снова. Обновление не должно принудительно перезагрузить текущий черновик.
8. Для передачи результатов сначала выберите разделы validation package. Отдельно решите, включать ли локальные диагностические события или фото. Просмотрите состав и получателя. Полный backup не отправляйте вместо числового пакета без отдельного согласования.

Можно остановить участие в любой момент и продолжить обычное использование приложения. Чтобы отозвать ранее переданные материалы, сообщите координатору свой код `[порядок связи]`; не отправляйте дополнительные персональные данные без необходимости. Удаление локальных данных и личных backup — отдельное решение. Координатор должен объяснить, какие переданные копии удалены и какие ограничения заранее согласованы.

Если инструкция, статус или действие непонятны, остановитесь на этом шаге и сообщите координатору. Не пытайтесь «исправить» результат изменением фактов ради совпадения с прогнозом.
