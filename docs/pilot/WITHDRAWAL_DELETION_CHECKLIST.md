# Черновик процедуры прекращения участия и удаления

**DRAFT — утвердить до внешнего набора.** Владелец `[ ]`, контакт `[ ]`, срок ответа `[ ]`, юрисдикция `[ ]`, сроки удаления рабочих/резервных копий `[ ]`.

1. Принять запрос по утверждённому каналу, проверить соответствие псевдониму минимально необходимым способом. Не запрашивать новые фото для идентификации.
2. Уточнить объём: остановка дальнейшего участия, удаление переданных данных, локальных данных или личных backup. Не связывать отказ от участия с запретом обычного использования приложения.
3. Прекратить запланированные приглашения/сбор. Отключить локальную диагностику по желанию участника — буфер вкладки очищается. Отказ от нового экспорта не удаляет ранее переданные файлы автоматически.
4. Найти переданные validation packages, изображения, таблицу соответствия кодов, рабочие производные и резервные копии у утверждённых получателей. Удалить по согласованному порядку; заранее определённые ограничения и сроки удаления backup сообщить участнику.
5. Локальное удаление выполнять только по явному решению участника. Перед очисткой объяснить потерю истории и предложить личный backup, если он хочет его сохранить. Удаление фото через приложение также удаляет связанные производные render-артефакты. Полная очистка данных сайта в браузере удаляет localStorage/IndexedDB; скачанные ZIP и внешние копии требуют отдельного удаления. Не удалять отдельные guard/recovery-ключи как способ «сброса ошибки».
6. Подтвердить выполненные действия и оставшиеся согласованные ограничения. В минимальном журнале исполнения хранить только разрешённые организационные сведения: код запроса, дату, действие, ответственного и дату подтверждения; срок этого журнала `[определить]`.

Проверка завершения: `[ ]` дальнейший сбор остановлен; `[ ]` активные переданные копии обработаны; `[ ]` резервные копии/производные учтены; `[ ]` локальные действия выполнены только по решению участника; `[ ]` подтверждение отправлено уполномоченным человеком. Автоматическая отправка сообщений из приложения отсутствует.
