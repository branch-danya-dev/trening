# Черновик карты данных пилота

**DRAFT, требуется правовая/privacy-проверка до внешнего набора.** Владелец `[ ]`, контакт `[ ]`, юрисдикция `[ ]`, срок хранения переданных данных `[ ]`, место/канал хранения координатора `[ ]` не определены.

| Данные | Где обрабатываются и хранятся | Передача |
|---|---|---|
| Профиль, факты, дни, питание, тренировки, гипотезы, ревизии | localStorage текущего origin; вычисления C#/WASM локально | Только выбранные разделы ручного экспорта |
| Оригинальные фото, уменьшенные JPEG/превью, анализ | IndexedDB `body3d-photos`; преобразование на устройстве | По умолчанию не передаются; отдельный явный opt-in |
| GeometryWarp-артефакты | Отдельные записи в том же IndexedDB, помечены synthetic | Отдельная загрузка/экспорт; не источник фактов |
| PIN | Ключ живёт в памяти; соль и проверочная запись локально; изображения AES-GCM | Backup может включать зашифрованные изображения и настройки; метаданные не считаются полностью зашифрованными |
| Локальная usability-диагностика | Отключена по умолчанию; до 256 разрешённых событий в памяти вкладки | Второй явный opt-in на включение в validation export; очистка при отключении/закрытии вкладки |
| Полный backup ZIP | Файл скачивается на устройство, содержит все выбранные приложением хранилища | Не отправляется автоматически; обращение с копиями — ответственность определённого владельца |
| Validation package | Числовые allowlisted поля, псевдонимизированные ссылки; заметки и локальные идентификаторы исключаются | Пользователь скачивает файл и отдельно решает, передавать ли его |

Псевдонимизация не гарантирует анонимность: сочетание дат, параметров тела и поведения может позволить сопоставление. До пилота утвердить минимальный набор экспорта и необходимость точных дат. Реальную таблицу соответствия кодов людям, если она вообще нужна, хранить отдельно от числовых пакетов; доступ и удаление определить до сбора.

Поток: ввод/фото → локальная проверка → локальные факты и ревизии → необязательный просмотр состава экспорта → скачивание → **отдельное добровольное действие передачи** утверждённому получателю. В этой задаче ни канала сбора, ни сервера, ни передачи участникам не создано.

Загрузка самого приложения и статических моделей требует обращения к хостингу при первом запуске/обновлении. Обычные технические журналы выбранного хостинга должны быть рассмотрены владельцем отдельно; отсутствие встроенной telemetry не означает отсутствие сетевых журналов хостинга. Модельные/pose-файлы поставляются локально с приложением; managed AI API и отправка фото отсутствуют.

Ограничения: очистка браузера, режим приватности или quota могут повлиять на сохранность; backup рекомендуется. Полный архив восстановления временно сохраняет before-image локально и удаляет его после успешного восстановления. Оставшийся после сбоя recovery marker нельзя удалять для обхода проверки. Browser persistence/usage estimates могут быть недоступны.

До пилота: определить основание и объём обработки, получателя, доступ, сроки удаления активных/резервных копий, порядок инцидентов и отзыва. Эти поля являются открытыми решениями, а не заявлением о юридической готовности.
