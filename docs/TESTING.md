# Как проверять приложение

Чек-лист для проверки приложения на реальных данных: что открыть, что проверить
и что прислать, если что-то не так. Снимки при этом не покидают устройство: для обратной связи хватает
цифр из «Отчёта для проверки».

## Где открыть

| Где | Как | Камера и PIN-код |
|---|---|---|
| Телефон | https://branch-danya-dev.github.io/trening/ — после включения GitHub Pages (ниже) | да |
| Компьютер | `dotnet run --project src/WorkoutCalculator.Web` → http://localhost:5256 | да (веб-камера) |
| Телефон по локальной сети | `dotnet run … --urls http://0.0.0.0:5256` → http://<адрес компьютера>:5256 | **нет** — браузер не даёт их странице без HTTPS |

**Один раз включить GitHub Pages:** Settings → Pages → Build and deployment → Source: **GitHub Actions**.
Затем Actions → Pages → последний запуск → **Re-run all jobs** (или любой пуш в main). Через пару минут
приложение откроется по адресу выше. На телефоне его стоит установить: Safari — «Поделиться → На экран
„Домой“», Chrome — «Установить приложение». Так браузер не сотрёт фото при нехватке места.

**Какая версия открыта.** Внизу раздела «Профиль» — «сборка xxxxxxx»: первые 7 знаков коммита. После
пуша в main установленное приложение скачивает новую версию в фоне и показывает плашку «Вышла новая
версия · Обновить».

## Что проверить

### 1. Перенос старых данных — если приложением уже пользовались

- [ ] После обновления сразу открывается модель, а не мастер: профиль, вес и обхваты на месте.
- [ ] «Профиль»: дата рождения — 1 января с пометкой «приблизительно» и подсказкой; «Изменить» → настоящая
      дата → пометка пропадает.
- [ ] Шкала дат под моделью: записи веса, дни начала планов и фотосессии — на своих датах.
- [ ] «Активность»: старые тренировки на своих днях, с пометкой о переносе.
- [ ] Перезагрузить страницу — ничего не задвоилось.

### 2. Первый запуск — мастер создания профиля

Проверить на чистом браузере (или в режиме инкогнито, или удалив данные сайта).

- [ ] «Создать профиль» → пол, дата рождения, рост, вес → «Далее» без них не пускает.
- [ ] Обхваты: модель с лентами показывает, где мерить; шаг можно пропустить.
- [ ] % жира: «Не знаю» → оценка прямо на шаге с подписью, по какой формуле (ВМС — если есть шея и талия).
- [ ] Фото можно пропустить; со снимками — разбор и подгонка, талия и бёдра по фото.
- [ ] Закрыть вкладку посреди мастера и открыть снова — продолжается с того же шага.
- [ ] «Готово» → своя модель на главном экране.

### 3. Модель, замеры и история

- [ ] Нажать на тело в районе талии, бедра, плеча, груди → виджет на этом замере, лента подсвечена
      (на телефоне — шторка снизу). Поворот пальцем шторку не открывает.
- [ ] Новый вес → модель меняется сразу; на шкале под моделью — сегодня с меткой. После перезагрузки на месте.
- [ ] Поменять дату в виджете на прошлую → внести вес → на шкале появилась эта дата; выбрать её — модель
      на ту дату. Серым — значения из прежних записей (с датой) или оценки.
- [ ] «Подробнее» → «Сердце»: пульс покоя и VO2max сохраняются.
- [ ] «Сравнить» → вторая дата → контур прежнего тела поверх нового; «Рядом» — две модели. Таблица
      «было → стало»: разница веса и обхватов верная.
- [ ] Удалить записи даты — с подтверждением, дата пропадает со шкалы.

### 4. Фото — главное, что нужно проверить на живых людях

**Условия съёмки:** облегающая одежда или бельё, однотонный фон, ровный свет, волосы собраны, без обуви;
телефон вертикально на уровне пояса в 2–3 м. Спереди — руки чуть в стороны; **сбоку — руки вдоль тела,
ноги вместе** (разведённые стопы сбивают масштаб на 4–5 %).

Фото — в виджете: «Подробнее» → «Фото» → «Добавить фото» (или шаг мастера).

- [ ] «Снять с подсказками»: подсказки понятны, снимок делается сам. Или «Фото спереди / сбоку» из галереи.
- [ ] Разбор (первый раз — до минуты): бирюзовый контур идёт по телу, а не по фону или одежде; точки у рук —
      там, где рука касается тела.
- [ ] **Обхваты по фото против ленты** (таблица под снимками). Талия и бёдра по фото должны быть в пределах
      ±2–3 см от ленты. Это ключевая цифра: формулы откалиброваны на людях ANSUR II, но на живых снимках
      ещё не проверены.
- [ ] Подгонка: «силуэт модели и фото расходились на X см, теперь Y» — Y заметно меньше; оранжевый пунктир
      модели ложится на контур, осанка модели похожа на вашу (прогиб, сутулость).
- [ ] **Повторяемость:** снять ещё раз через 5 минут (отойти и встать заново), а на следующий день — ещё раз.
      Сравнить даты с фото: «Сравнить фото» — изменения не больше 0,5 см. Это уровень шума.
- [ ] Через неделю-две — новые фото: карта изменений и «было → стало» совпадают с лентой по знаку
      и порядку величины.

### 5. Активность

- [ ] «+ Тренировка» → реальная тренировка с дорожки (скорость, уклон, время) и данные с часов; время
      начала. Сравнение «Apple Watch: … на N% больше/меньше оценки» правдоподобно, методы в «Как считали»
      не расходятся в разы.
- [ ] «Скорость или уклон менялись»: несколько отрезков, «+ Отрезок» и «×» работают; ошибка в поле
      подсвечивает его и ставит в него курсор.
- [ ] Улица: дистанция, время и набор высоты из часов.
- [ ] Три тренировки за два дня → в календаре два дня с точками; итоги дня и недели — суммы тренировок.
- [ ] Тренировка в 00:30 — в своём дне, а не в предыдущем.
- [ ] Строка «расчёт по весу X кг на дату»: вес — с той даты. Внести новый вес сегодня → вчерашняя тренировка
      не изменилась.
- [ ] Правка тренировки (поля на месте, калории пересчитались) и удаление с подтверждением.

### 6. Профиль, защита и резервная копия

- [ ] Установить PIN-код → «Закрыть снимки» → «Сравнить фото» и новые фото просят открыть снимки PIN-кодом;
      неверный PIN-код — ошибка, верный открывает. Свернуть приложение больше чем на 2 минуты или
      перезагрузить → снова закрыты.
- [ ] «Размывать снимки» и водяной знак видны; в переключателе приложений снимки размыты.
- [ ] **«Сохранить копию»** → файл скачался. Открыть его на компьютере: `data.json` и папки со снимками (JPEG).
- [ ] Что-нибудь поменять → «Восстановить из копии» → видно, что в файле, → «Заменить всё» → всё как
      в момент копии, фото на месте.
- [ ] **Другое устройство или браузер:** на приветствии мастера «Восстановить из резервной копии» →
      модель, история, тренировки и фото — как на первом.
- [ ] Чужой файл (любой zip) — понятная ошибка, данные не тронуты.

### 7. Офлайн

- [ ] Установленное приложение без интернета (авиарежим) открывается, модель строится, фото на месте.

## Что прислать

- **«Отчёт для проверки»** — ссылка под таблицей разбора фото. Только цифры: профиль,
  ширина и глубина на уровнях груди, талии и бёдер, обхваты по фото против ленты, итог подгонки,
  сборка, браузер и экран. Ни снимков, ни контуров в нём нет. «Скопировать» — и вставить в сообщение.
- Скриншот, если что-то выглядит неправильно: с включённым размытием снимки на нём не видны, контуры остаются.
- Что делали, что ожидали, что получилось; устройство и браузер.

## Известные ограничения

- Обхват груди по фото не считается: в ANSUR II ширину груди мерили иначе, чем её видно на снимке.
- На модели MakeHuman формула завышает бёдра на 5–6 см (сечение бёдер у неё «площе», чем у людей); насколько
  точно на людях — как раз то, что нужно проверить.
- Гипотезы и прогноз скрыты (прежний экран — `?classic=1`) и работают со старыми данными, а не с записями
  замеров.
- Запретить снимок экрана веб-страница не может; PIN-код защищает от чужих рук, а не от взлома телефона.
