# Visual review

Reviewed synthetic outputs at 390 and 1400 px, with 320 px coverage for onboarding, CheckIn, nutrition entry, close-day review, awaiting/evaluated hypothesis and recovery. The five-section smoke separately covers 768 and 1024 px.

- Model framing leaves the full body visible between the upper/lower controls. Previous/current versions are reconstructed from immutable records, and the future endpoint is explicitly requested in the Plan screenshots. Contrast of the current-body contour was adapted to the light surface.
- Today leads with date, state and quick entry; calendar, weekly load and detailed source information are disclosed. Editors stack at narrow widths; close-day review has keyboard focus and an explicit confirmation.
- Plan now shows weight/waist first, all remaining predicted values behind a disclosure, and the evaluated outcome before the original prediction details. Manual scenarios remain separate.
- Photos, source labels, rejected-photo results, quota and corrupt-data states remain legible. Unknowns are not shown as zero. WebGL failure has a text fallback with working navigation and factual CheckIn.
- Native fixed bottom navigation appears at the viewport boundary in full-page mobile captures. It is not duplicated navigation halfway down the actual page; the screenshot contains content below that viewport.
- No page-level horizontal overflow in 73 captures. Deliberately wide comparison tables/calendar have labelled local scrolling surfaces.

The gallery is layout evidence from desktop Edge with synthetic data. It does not certify physical-phone performance, assistive technology behavior or physiological prediction accuracy. No user testing or recruitment was performed.
