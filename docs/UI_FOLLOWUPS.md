# UI follow-ups

These are deferred conveniences, not new domain functionality in UI V1.

- Empirical usability study after owner approval and completion of the existing consent/privacy documents. No participant recruitment in this PR.
- Physical low-end phone and assistive-technology evaluation; desktop emulation is not real-device evidence.
- A future versioned storage migration for bounded history writes, only as separate architecture work. The existing 1000-day/fresh CheckIn ratio limitation remains.
- Food search, barcodes, wearables, social/coaching, accounts/cloud sync and monetization remain outside the current product scope.
- No AI renderer, DeltaShape, Pseudo-DXA or new physiology is implemented. Research providers remain inaccessible in normal settings.
- Correction of already confirmed days still requires future domain design; UI explains current immutability.
- Last successful backup date is not tracked by the current service. UI must continue saying that explicitly.

Additional findings from final browser/visual review are recorded in UI_REDESIGN.md with actual validation status.
